## Codex Migrate Current 1.1.0-current.5

推荐下载 `Codex-Migrate-Current-1.1.0-current.5-Standalone-Windows-x64.exe`，直接双击运行，无需同目录的 CLI 或额外 VC++ 运行库。MIT 署名和完整第三方许可已内置，可在“设置 → 关于独立运行版”查看和保存。

- **选择性导出**：进入导出页自动列出本机活动和归档对话，默认不选中；支持单条、按项目或全选。仅导出所选对话和必要的分叉祖先，保留名称、归档状态与项目关系。
- **自动创建目录**：导入页额外目录默认使用原始本机绝对路径。缺失时在正式导入阶段创建，预览不写入；仍可选择其他位置或使用主项目目录。
- **失败日志与回滚**：创建失败显示具体路径和原因，同名文件不会覆盖。失败或手动回滚只移除本次新建且仍为空的目录，保留已有目录和用户文件。

已用 Desktop `26.1021.3705.0` / `codex-cli 0.164.0-alpha.11.1` 验证 49 项常规 Rust 测试、1 项 GUI 原生流程和 20 项原生迁移场景，并验证独立 EXE 单文件启动。测试均为隔离合成数据；未执行真实账号完整 GUI 导入或干净 Windows 虚拟机验收。

仅迁移本地 Codex 代码对话，不迁移 Chat/Work 云端历史。新版历史导入仍需要目标电脑安装匹配的 Desktop / Codex 运行时。自动创建的是空目录，原项目文件和附件需要另行复制。旧备份继续支持；新的选择性导出包请使用 current.5 导入。

另附 GitHub Actions 构建的 Windows x64 MSVC ZIP，包含 GUI 和 CLI；该 ZIP 需要 Microsoft Visual C++ v14 x64 运行库。独立 EXE 的校验值、构建信息和验证结果一并提供。本次仍为预发布版。
